# WordQuest — Antigravity Submission Package

This folder contains the documentation and traces for the WordQuest project
submission to **Google Antigravity Hackathon #AISeekho2026 — Challenge 4:
Agentic Game Quest.**

## Contents

| File | Purpose |
|---|---|
| `01-implementation-plan.md` | High-level architecture, phases, key decisions |
| `02-task-list.txt` | Full chronological task list (git commit history) |
| `03-agent-walkthrough.md` | Detailed design + responsibility of each of the 9 agents |
| `04-agent-traces-sample.md` | Real request/response captures from the live backend |
| `screenshots/` | UI screenshots from the running app (add manually) |

## How to zip and submit

```bash
# from the wordquest/ folder:
zip -r antigravity-submission.zip antigravity-submission/
```

Then upload `antigravity-submission.zip` as the "Antigravity Trace / Logs"
submission item.
