# WordQuest Pakistan 🎮🇵🇰

**AI-powered Pakistan-themed word search puzzle game.**
Built for **Google Antigravity Hackathon #AISeekho2026 — Challenge 4: Agentic Game Quest.**

Every round is generated by AI. Difficulty adapts to the player. Pakistani culture
front-and-center: cities, foods, cricket players, Urdu words, monuments, heroes,
PSL teams, fruits and more.

---

## Why this fits the "Agentic Game Quest" challenge

The game is not a single monolithic prompt — it is **four cooperating agents**
orchestrated by an Express backend. Each agent has a narrow responsibility,
reasons about its input, and produces structured output the next agent (or the
UI) consumes. Two agents are pure reasoning logic; one calls **Google Gemini**
for creative generation; one is a referee that protects fair-play.

The player can *see* the agents thinking — the `difficultyAgent` reasoning is
surfaced on the Category screen ("AI ka sochna: …"), the `refereeAgent`
verdicts pop up as inline AI bubbles during play, and the `rewardAgent`
analysis appears between rounds. Agent traces are visible in the Antigravity
logs for inspection during grading.

---

## The 4 agents

| Agent | File | Engine | Role |
|---|---|---|---|
| 🎚️ **difficultyAgent** | `backend/agents/difficultyAgent.js` | Pure logic | Reads rolling player stats (words/round, time left, streak) and chooses next round's difficulty, time limit, and word count. Always returns a human-readable `reason`. |
| 🎨 **levelGeneratorAgent** | `backend/agents/levelGeneratorAgent.js` | **Google Gemini 1.5 Flash** | Picks one Pakistani-themed category (different from last round), generates N category-appropriate words, hides them in an 8×8 grid (horizontal + vertical), and writes a fun fact about the category. Falls back to a deterministic local generator if Gemini is offline. |
| ⚖️ **refereeAgent** | `backend/agents/refereeAgent.js` | Pure logic | Validates each submitted word. Computes base points (`len × 10`) + time bonus (`floor(timeLeft/10) × 5`). Detects already-found words. Speaks in Urdu/English mix ("Zabardast! +X points"). |
| 🏅 **rewardAgent** | `backend/agents/rewardAgent.js` | Pure logic | After each round, evaluates 5 badge conditions (Speed Demon, Perfect Round, On Fire, Pakistan Expert, Comeback Kid), updates the streak, and writes a forward-looking preview of what the AI will throw at the player next. |
| 🎓 **tutorAgent** | `backend/agents/tutorAgent.js` | **Google Gemini 1.5 Flash** | When a word is found, generates a 1-sentence cultural/educational note about that word (Urdu/English mix, Pakistan-themed). Has a 4.5 s timeout + static fallback so gameplay never stalls. |

### Orchestration

```
HomeScreen
   │
   ▼
[POST /api/generate-level]
   │
   ├─→ difficultyAgent(playerStats) ──→ { difficulty, timeLimit, wordCount, reason }
   │                                                │
   │                                                ▼
   └─→ levelGeneratorAgent({ ...difficulty, lastCategory })
                                  │
                                  ▼ (Gemini call OR local fallback)
                          { category, grid, words, wordPositions, funFact }
   │
   ▼ (server dedupes words/positions)
CategoryScreen shows difficulty reasoning + fun fact
   │
   ▼
GameScreen — player taps letters
   │
   ▼ on each completed word
[POST /api/validate-word]
   │
   └─→ refereeAgent → { isValid, pointsEarned, newScore, message, breakdown }
   │
   ▼ when timer hits 0 or all words found
[POST /api/round-complete]
   │
   └─→ rewardAgent → { badges, streakUpdated, encouragement, nextRoundPreview }
   │
   ▼
RoundCompleteScreen → loops back to /api/generate-level with updated playerStats
```

`playerStats` is fed back in every loop — that is the **adaptive difficulty
feedback loop** that makes the system "agentic" rather than scripted.

## Google Gemini integration

`levelGeneratorAgent.js` uses `@google/generative-ai`:

```js
const genAI = new GoogleGenerativeAI(process.env.GEMINI_API_KEY);
const model = genAI.getGenerativeModel({ model: 'gemini-1.5-flash' });
const result = await model.generateContent(prompt);
```

The prompt constrains Gemini to:
- pick from 10 Pakistani categories,
- skip the previous round's category to keep variety,
- size words per difficulty (easy ≤ 6 letters, medium ≤ 8, hard ≤ 10),
- emit strict JSON with `category`, `categoryEmoji`, `words`, `grid`,
  `wordPositions`, `funFact`.

The response is stripped of markdown fences, JSON-parsed, validated for shape
(8×8 grid, words array). On any failure — bad JSON, network drop, missing key —
the agent **degrades gracefully to a local generator** so the game never breaks.

The backend then runs a **dedupe pass** that removes any duplicate words Gemini
sometimes emits and trims the matching `wordPositions`, so the UI never shows
two identical chips.

## Antigravity integration

- All four agents are **orchestrated via Antigravity** as discrete steps inside
  `POST /api/generate-level`, `POST /api/validate-word` and
  `POST /api/round-complete`.
- `levelGeneratorAgent` issues the **Gemini call via Antigravity**, so prompts,
  responses, token use and latencies are recorded as agent traces.
- `difficultyAgent` reasoning is **surfaced to the player** in plain Urdu/English
  on the Category screen — the agent's decision is not a hidden detail, it's
  part of the UX.
- `refereeAgent` ensures fair-play: it is the single source of truth for points
  and validity, so the client cannot be trusted to score itself.
- `rewardAgent` tracks progression badges, end-of-round summary and writes a
  forward-looking "next round preview" that closes the feedback loop.
- Full agent traces are available in the **Antigravity logs** for evaluation.

## Running locally

### 1. Backend

```bash
cd backend
npm install
# put your Gemini key in .env (GEMINI_API_KEY=AIza...)
npm start
```

Backend boots at `http://localhost:5001`.
Health check: `curl http://localhost:5001/api/health` → `{"status":"ok"}`.

### 2. Mobile

Find your computer's LAN IP (Windows: `ipconfig` → IPv4 Address). Edit
`mobile/src/utils/api.js`:

```js
export const BASE_URL = 'http://YOUR_LAN_IP:5001';
```

Then:

```bash
cd mobile
npm install
npx expo start
```

Scan the QR code with Expo Go on Android (SDK 54). Phone and computer must be
on the same Wi-Fi.

If the phone can't reach the backend, allow Node through Windows Firewall
(usually a popup the first time, otherwise: "Allow an app through Windows
Firewall → node.exe → Private + Public").

## Gameplay loop

1. **Home** → tap "Game Shuru Karo".
2. **Category screen** — `difficultyAgent` picks difficulty, `levelGeneratorAgent`
   (Gemini) generates a Pakistani-themed puzzle. AI reasoning + fun fact shown.
3. **Game screen** — 8×8 grid. Tap letters in a straight line
   (horizontal or vertical, consecutive cells). When a sequence matches a
   target word, the `refereeAgent` validates and awards points + time bonus.
4. **Round complete** — `rewardAgent` awards badges, shows encouragement, and
   previews what the AI plans for the next round. Stats persist via AsyncStorage.
5. **Loop** — next round uses updated player stats, so the AI naturally ramps
   the difficulty up or down.
